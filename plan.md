# План: роли героев

## Цель

Добавить героям одну из трёх ролей:

- `attacker` — повышенный урон;
- `defender` — создаёт общий щит команды;
- `healer` — восстанавливает общее HP команды.

Роли должны срабатывать автоматически при сборе цепочки стихии героя. Не добавлять ману, активные кнопки и новые валюты.

## Распределение ролей

### Герои

- Наруто — `attacker`
- Рем — `defender`
- Зоро — `attacker`
- Аква — `healer`
- Итачи — `attacker`
- Куруми — `healer`
- Сайтама — `attacker`
- Микаса — `attacker`
- Ренгоку — `defender`
- Годжо — `defender`

Обоснование:

- Ренгоку защищает команду пламенной волей — это также добавляет огню вторую роль.
- Рем принимает удар на себя.
- Годжо защищает команду «Бесконечностью».
- Аква лечит божественной магией.
- Куруми восстанавливает состояние команды через управление временем.
- Остальные специализируются на прямом уроне.

### Духи

- Саламандра — `attacker`
- Ундина — `healer`
- Дриада — `defender`
- Светлячок — `healer`
- Тень — `attacker`

Так роли доступны уже в стартовой команде независимо от выбранного героя.

## Боевая механика

Все роли продолжают атаковать врага. Различается коэффициент урона и дополнительный эффект.

### Атакующий

- множитель урона: `1.25`;
- дополнительных эффектов нет.

Формула:

```ts
finalDamage = currentDamage * 1.25;
```

### Защитник

- множитель урона: `0.85`;
- после атаки добавляет щит команде.

Формула щита:

```ts
shield = unit.hp * (0.10 + 0.02 * (chainLength - 3));
```

Округлять до целого.

Примеры:

- цепочка 3: 10% HP защитника;
- цепочка 5: 14%;
- цепочка 7: 18%.

Ограничение общего щита:

```ts
teamShield <= teamMaxHp * 0.25;
```

Щит:

- сохраняется между ходами и волнами;
- сначала поглощает урон врагов;
- не считается HP;
- не влияет на звезду за оставшееся здоровье;
- начинается с нуля в каждом бою.

### Лекарь

- множитель урона: `0.75`;
- после атаки восстанавливает HP команды.

Формула лечения:

```ts
heal = unit.hp * (0.08 + 0.015 * (chainLength - 3));
```

Округлять до целого.

Лечение:

- не превышает `teamMaxHp`;
- применяется после атаки;
- показывать только фактически восстановленное HP;
- при полном здоровье показывать «HP заполнено» либо не создавать число лечения.

## Изменения данных

### `src/data/cards.ts`

Добавить тип:

```ts
export type HeroRole = 'attacker' | 'defender' | 'healer';
```

В `CardDef` добавить обязательное поле:

```ts
role: HeroRole;
```

Назначить роль каждой карте, включая духов.

Добавить русские названия:

```ts
export const ROLE_NAME: Record<HeroRole, string> = {
  attacker: 'Атакующий',
  defender: 'Защитник',
  healer: 'Лекарь',
};
```

При необходимости добавить короткие подписи:

```ts
export const ROLE_SHORT: Record<HeroRole, string> = {
  attacker: 'АТК',
  defender: 'ЩИТ',
  healer: 'ЛЕК',
};
```

Сохранение менять не нужно: роль находится в статических данных карты.

## Расчёты ролей

Создать `src/battle/roles.ts`.

Вынести туда:

- коэффициенты урона;
- расчёт щита;
- расчёт лечения;
- ограничение минимальной длины цепи.

Предлагаемый API:

```ts
export function roleDamageMultiplier(role: HeroRole): number;
export function shieldForChain(unitHp: number, chainLength: number): number;
export function healForChain(unitHp: number, chainLength: number): number;
```

Функции должны быть чистыми и не зависеть от Phaser.

## Изменения боя

### `src/scenes/BattleScene.ts`

В `Unit` добавить:

```ts
hp: number;
```

В `createTeam()` сохранять `stats.hp` в юните.

Добавить состояние:

```ts
private teamShield = 0;
```

Обнулять его при создании или перезапуске боя.

### Урон героя

В `heroAttack()` применить коэффициент роли до округления итогового урона:

```ts
damage *= roleDamageMultiplier(unit.def.role);
```

После атаки:

- `defender` добавляет щит;
- `healer` восстанавливает HP;
- `attacker` ничего дополнительно не делает.

Дополнительный эффект должен сработать и при убийстве врага этой атакой.

### Получение урона

В `foeAttack()`:

1. Вычислить, сколько урона поглотил щит.
2. Уменьшить `teamShield`.
3. Остаток снять с `teamHp`.

Пример:

```ts
const blocked = Math.min(this.teamShield, foe.def.atk);
const damage = foe.def.atk - blocked;

this.teamShield -= blocked;
this.teamHp = Math.max(0, this.teamHp - damage);
```

Показывать отдельные сообщения:

- `Щит -120`;
- `-80 HP`.

Если весь удар поглощён, красное число урона не показывать.

## Интерфейс

### Карточки героев

В `src/ui/widgets.ts`, внутри `cardView()` добавить небольшой бейдж роли:

- `АТК`;
- `ЩИТ`;
- `ЛЕК`.

Бейдж не должен перекрывать стихию, уровень, имя и редкость.

Роль должна быть видна минимум на экранах:

- выбора стартера;
- команды;
- коллекции;
- прокачки;
- призыва.

Поскольку они используют `cardView()`, желательно реализовать отображение централизованно.

### Бой

Строка здоровья команды:

```text
HP 2450 / 3000    Щит 180
```

При лечении показывать зелёное число:

```text
+75 HP
```

При получении щита — голубое:

```text
+120 Щит
```

При поглощении урона:

```text
Щит -120
```

Не создавать отдельное HP для каждого персонажа.

## Поведение нескольких героев одной стихии

Сохранить текущую механику:

- все герои соответствующей стихии действуют по очереди;
- каждый применяет эффект своей роли;
- несколько лекарей лечат последовательно;
- несколько защитников последовательно добавляют щит;
- итоговый щит всё равно ограничен 25% `teamMaxHp`.

Не вводить ограничение «один герой каждой стихии» в рамках этой задачи.

## Баланс

Начальные значения:

- атакующий: `1.25` урона;
- защитник: `0.85` урона;
- лекарь: `0.75` урона;
- щит: 10% HP защитника за цепочку 3;
- лечение: 8% HP лекаря за цепочку 3;
- максимум щита: 25% общего HP.

После реализации проверить главу 1 всеми стартерами.

Ожидаемый результат:

- Наруто быстрее завершает бой;
- Рем получает меньше фактического урона благодаря щиту;
- Зоро наносит повышенный урон, а лечение получает от Ундины;
- Аква заметно помогает после открытия на 1-2;
- лечение не должно полностью отменять опасность босса;
- Король Гоблинов не должен стабильно проходиться на 3 звезды без прокачки.

Если глава стала слишком лёгкой, сначала уменьшать лечение и щит, а не повышать HP врагов.

## Проверки

Обязательно проверить:

1. Щит полностью поглощает слабый удар.
2. Сильный удар сначала ломает щит, затем снимает HP.
3. Щит не превышает 25% максимального HP.
4. Лечение не превышает максимальное HP.
5. Лечение влияет на звезду за здоровье.
6. Щит на эту звезду не влияет.
7. Эффекты корректно работают при нескольких героях одной стихии.
8. После перезапуска боя щит равен нулю.
9. Роли отображаются на карточках.
10. Старые сохранения загружаются без миграции.
11. Быстрый бой и сюжетные этапы запускаются без ошибок.

После изменений выполнить:

```bash
npm run typecheck
npm run build
```

Не добавлять библиотеки и не менять формат сохранения.
