# Spirit Stones Anime

Браузерная игра на Phaser 3, TypeScript и Vite. Экран портретный, 720×1280. Игрок соединяет цепочку камней одной стихии, и герой этой стихии бьёт. Текст для игрока — по-русски. Тон сюжета: лёгкий юмор и серьёзные бои.

## Команды

- `npm run dev` — игра на http://localhost:5173
- `npm run typecheck` — проверка типов после правок кода
- `npm run build` — сборка
- `npm run sprites` — только когда менялись JPG в `art/units/`

## Куда писать данные

Игра читает TypeScript, не заметки.

- Сюжет, этапы, реплики: `src/data/story.ts`. Реплика с `requires` звучит, только если этот герой уже в коллекции. `speaker: 'starter'` — герой, выбранный в начале.
- Враги: `src/data/enemies.ts`. Особые способности босса — поле `traits`, без отдельного кода на каждого босса.
- Герои: `src/data/cards.ts`. Сюжетный герой получает `unlock` и не выпадает из призыва.
- Стихии: `fire`, `water`, `earth`, `light`, `dark`. Огонь бьёт землю, земля — воду, вода — огонь, свет и тьма бьют друг друга.
- План глав: `docs/story.md`. Это черновик. В игре работает только то, что перенесено в `src/data/`.

Глава 1 «Лес Новичков» уже играется. Главы 2–5 в данных помечены как ещё не готовые. Новую главу собирай по образцу первой: враги, этапы с волнами и `parMoves`, реплики до и после боя, награда-камень.

## Как менять код

Сначала смотри существующую сцену или данные и повторяй их форму. Бой живёт в `src/scenes/BattleScene.ts` и `src/battle/BoardModel.ts`. Не добавляй библиотеки без просьбы. После правки TypeScript запускай `npm run typecheck`.
